# Visión

Aries OS será una plataforma de asistentes inteligentes modular, escalable y de bajo costo.

## Objetivos
- Modularidad
- Escalabilidad
- Bajo costo
- Offline-first
- Arquitectura desacoplada

## Principios
1. El núcleo no depende de plugins.
2. Los plugins se comunican por contratos.
3. La documentación guía el código.
